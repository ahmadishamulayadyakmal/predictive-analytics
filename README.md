# Predictive Analytics

Repository untuk pembelajaran dan pengembangan proyek *predictive analytics* menggunakan machine learning.

> Repository saat ini berisi template laporan proyek dari dicoding.

## Isi Repository

- [`REPORT_TEMPLATE.md`](REPORT_TEMPLATE.md): template laporan proyek yang mencakup pemahaman bisnis, data, pemodelan, dan evaluasi.

## Alur Proyek

Alur standar untuk menyelesaikan proyek predictive analytics:

1. Memahami domain dan permasalahan bisnis.
2. Menentukan problem statement, goals, dan solution statement.
3. Memahami struktur, kualitas, dan karakteristik data.
4. Melakukan data preparation dan exploratory data analysis.
5. Melatih serta membandingkan model machine learning.
6. Mengevaluasi model menggunakan metrik yang sesuai.
7. Menyusun hasil, kesimpulan, dan rekomendasi.
